# Module structure

The lecture sequence has been preserved while adjacent slides are grouped into 20 manageable modules. Every module follows: introduction -> objectives -> simple explanation -> lecture-grounded formal wording -> interactive visual -> examples -> key terms -> recall and practice -> notes.

## Chapter 5 - Infrastructure (35 concepts, pages 4-56)

1. Network foundations - architecture, physical/logical networks, VLANs, OSI, wired networks and the jack-IDF-MDF path
2. Office network design - subnet strategies, NAC and enterprise wireless design
3. Datacentre & WAN networks - central/TOR/fabric designs, zones, topology, links and routing
4. Internet, IPv6 & operations - access, resilience, SDN, IPv6, monitoring, management, lifecycle, documentation and support
5. Datacentre operations - facility choices, requirements, capacity, equipment lifecycle, labelling, console, tools and spares

## Chapter 6 - Helpdesks & Support (35 concepts, pages 4-39)

1. Customer support
2. Support process & tickets
3. Incident handling: four phases and nine steps
4. Debugging methods
5. Durable fixes & documentation

## Chapter 7 - Change Processes (31 concepts, pages 4-44)

1. Change governance
2. Server upgrades
3. Maintenance windows
4. Centralisation models
5. Recommendations & migration

## Chapter 8 - Service Recommendations (38 concepts, pages 4-50)

1. Monitoring & namespaces
2. Name-service reliability
3. Email & print services
4. Storage, backup & recovery
5. Repositories & web services

Stable chapter, module, concept and diagram IDs are independent of display order, protecting saved progress if the content is extended.
