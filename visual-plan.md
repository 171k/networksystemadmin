# Visual plan

The site uses an original, reusable CSS/React process-map system instead of copying slide artwork. It supports keyboard-selectable nodes, step highlighting, show/hide labels, test mode, explanation steps, reset and responsive overflow.

## Chapter 5 visual vocabulary

Physical/logical overlays; VLAN lanes; jack-IDF-MDF path; core/distribution/edge; wired/wireless; central switch, TOR and fabric; dual-switch resilience; WAN topology and dedicated/VPN comparison; routing; Internet SPOF; IPv6 sequence; monitoring flow; datacentre capacity and equipment lifecycle.

## Chapter 6 visual vocabulary

Physical/virtual helpdesk; support scope; request and escalation flow; ticket priority; four phases and nine steps; customer goal versus technical cause; root cause; elimination and refinement; temporary/permanent fixes; safe automation; documentation lifecycle and CMS layers.

## Chapter 7 visual vocabulary

Change lifecycle; CRB tiers; impact-likelihood risk matrix; five-part technical plan; freeze calendar; 16-step server-upgrade checklist; three maintenance stages; shutdown/boot dependencies; HA maintenance; central/decentral/distributed models; seven-step migration.

## Chapter 8 visual vocabulary

Real-time versus historical monitoring; alert cascade; namespace structure and policy; DNS anycast; authoritative DNS, DHCP, LDAP and AAA dependencies; email pipeline; print policy; storage architectures; backup/restore and recovery SLA; repository promotion; horizontal/vertical web scaling; security-reliability relationship.

All visual labels and explanations are reconciled to their cited lecture pages. Decorative, external and copied stock imagery is excluded.
